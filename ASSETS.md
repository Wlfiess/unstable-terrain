# Source and asset scope

The Fabric project's existing MIT license is included under `source/fabric/LICENSE`. Preserve that notice when redistributing the covered code. The source snapshot does not transfer rights to imported assets or to third-party branding.

The local release contains extracted geometry from reference worlds and schematics, including a supplied Horace Creations tree pack, the Lakerek Temple, the Prince Zam Empire, and the Orbital installation. Even the no-landmark JARs share terrain and tree resources with the standard builds. Distribution permission for these resources was not verified. That permission needs to cover the embedded or converted copies before the JARs and source assets are uploaded publicly.

The Git snapshot omits imported voxel assets, world saves, schematics, generated core libraries, and release JARs. Building the complete project requires restoring the omitted resources from the local source workspace and generating the Paper core from Fabric as described in the Paper project tooling.

The UT icon combines an in-game Floating Farlands screenshot with typeset letters. See [Modrinth Content Rules](https://modrinth.com/legal/rules) and [CurseForge Moderation Policies](https://support.curseforge.com/support/solutions/articles/9000197279) for publication and disclosure requirements.
